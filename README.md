# NextSelf

A gamified study-time tracker that turns focused study sessions into rewards.

## Overview

NextSelf helps you build consistent study habits by converting focused work into a reward system. Study in fixed sessions, earn diamonds, and spin a reward wheel to unlock screen time.

## How It Works

1. **Start a Study Session** — Each session runs for 45 minutes. An alarm rings when the session ends.
2. **Earn Diamonds** — Completing 2 sessions earns you 20 diamonds.
3. **Spin the Wheel** — Spend diamonds to spin a reward wheel that grants random screen time (e.g., 30 / 45 / 60 minutes).
4. **Stack Your Rewards** — Rewards from multiple spins stack, giving you a pool of earned screen time to use as you like.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js

## Features

- Session timer with alarm notification on completion
- Diamond-based reward economy tied to study consistency
- Spin-wheel mechanic with randomized rewards
- Stackable reward time tracking

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Himanshu-cyber-alt/Server-NextSelf.git
cd Server-NextSelf

# Install dependencies
npm install

# Run the server
npm start
```

## Motivation

Built to help stay focused during long study/job-search stretches by turning discipline into a game — earn your downtime instead of just taking it.
